    Fiddle Tablature Legend

    Format: String + Finger (e.g., D1 = D string, 1st finger)

    E = 1st string (highest)
    A = 2nd string
    D = 3rd string
    G = 4th string (lowest)
    0 = Open string
    1 = 1st finger
    2 = 2nd finger
    3 = 3rd finger
    4 = 4th finger
    L = Low (half-step back, e.g., AL2 = low 2nd finger on A)
